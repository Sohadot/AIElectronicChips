# IDE-008: Evidence Freshness and Conflict Maintenance

- **Inspection log:** [`data/source-inspections.json`](data/source-inspections.json). It records what one inspection run observed for each of the 73 registry records.
- **Conflict register:** [`data/evidence-conflicts.json`](data/evidence-conflicts.json). It holds 11 material conflicts and open evidence questions.
- **Impact index:** [`data/evidence-impact-index.json`](data/evidence-impact-index.json). It is generated, and for each source it lists what needs re-examination if that source changes.
- **Public view:** [`/sources/#evidence-maintenance`](sources/index.html), sections 08–10, generated by `scripts/render_evidence_maintenance.py`.
- **Inspection command:** `scripts/inspect_sources.py`. It needs network access, is run explicitly and never runs in CI.
- **Validator:** `scripts/validate_evidence_maintenance.py`. It runs offline in `validate_all.py`.
- **Tests:** `tests/test_evidence_maintenance.py`.

None of these files is a human scientific review, an Atlas or an approval. The Atlas still has 0 approved relationships.

## Running a new inspection

1. **Fetch.** Run `python3 scripts/inspect_sources.py --date YYYY-MM-DD <source IDs>`. It writes raw observations to `build/`. It never edits the registry and never changes `accessed_at` or `status`.
2. **Record.** Review the observations. Then add a run and its records to `data/source-inspections.json`, with notes and a next action for each source.
3. **Update the register.** Update `data/evidence-conflicts.json`. Add history entries; never overwrite earlier ones.
4. **Regenerate.** Run `python3 scripts/validate_evidence_maintenance.py --write` to rebuild the impact index, then `python3 scripts/render_evidence_maintenance.py` and `python3 scripts/render_reference_pathways.py`.
5. **Validate.** Run `python3 scripts/validate_all.py`.

The inspector sends one request per URL with an honest, declared user agent. A site that refuses it is recorded as inaccessible. The inspector does not impersonate a browser and does not retry with altered identity.

## The 2026-11-10 run

- **Metadata.** All 73 records pass the metadata checks.
